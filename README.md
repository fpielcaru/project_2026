# Educational Phishing Lab

A simple Flask web server built for **learning purposes only**.  
It demonstrates how phishing pages collect credentials and how a backend can receive and display that data.

> **Warning:** This project is for educational use only.  
> Use only fake test data (e.g. `test@example.com`). Do not use real credentials.

## Features

- Web form that simulates a login page
- POST endpoint that receives submitted data
- Page to view all received records (`/view-data`)
- Basic server stats (`/stats`)
- Simple API test endpoint (`/api/test`)
- Warning when a real email domain is entered

## Tech stack

- Python 3
- Flask
- HTML / CSS / JavaScript (inline frontend)
